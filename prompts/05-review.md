# Step 5 — Independently review the result

Prefer a **fresh Codex session** that did not implement the code.

```text
Read AGENTS.md and feature 001's specification.
Do not modify any files.

For every acceptance criterion, classify the implementation as:
met (name a test), partially met, or missing.
Look for untested error paths, missing authorization constraints,
scope creep, weak assertions, and discrepancies between plan and code.
Say what test evidence establishes and what it cannot establish.
```

**Human checkpoint:** Decide whether the feature is acceptable and
whether the *specification itself* missed an important requirement.
